# Auth Backend API

A complete authentication backend built with Node.js, Express, MongoDB, JWT, Nodemailer, and Mailtrap.

## Features

- User Registration
- Login Authentication
- JWT Token Authentication
- Email Verification
- Forgot Password
- Reset Password
- Logout User
- Protected User Route
- Password Hashing using bcrypt
- MongoDB Database Integration

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- Nodemailer
- Mailtrap
